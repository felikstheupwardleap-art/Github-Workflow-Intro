# Github-工作流简介
1. 创建仓库 HelloWorld
        <br>↓<br>
2. main 是默认正式分支
        <br>↓<br>
3. 从 main 创建 readme-edits 分支
        <br>↓<br>
4. 在 readme-edits 里面修改 README
        <br>↓<br>
5. commit changes 保存这次修改
        <br>↓<br>
6. open pull request 发起合并请求
        <br>↓<br>
7. merge pull request 合并回 main
        <br>↓<br>
8. main 现在也有了 README 的修改
